출발 순서

  • 브레이크 S(또는 발 페달) 밟기 → 오른쪽 D 누르기
  • 주차 브레이크 해제: 오른쪽 (P) 버튼 또는 Space → 브레이크 떼기: 크리프로 출발
  • 1인칭: 오른쪽 위 1인칭 또는 V. 위에서 보기 T

조향 · 원을 그리며 돌리기

  • 화면 아무 곳(버튼 제외)에서 손가락이나 마우스 휠 클릭으로 원을 그리세요. 시계 방향 = 오른쪽
  • 원 한 바퀴 = 핸들 한 바퀴 (크기·위치 무관). 직선으로 밀면 돌지 않음. 핸들 ±540°, 앞바퀴 최대 35°
  • 손을 떼도 각도 유지, 다시 그리면 이어서. 가운데 흐린 핸들 그림은 현재 각도 표시용

발 페달 키보드

  • 일시정지 → 페달 보정: 브레이크 5회 → 가속 5회 → 키 확인 → 실제 테스트 통과 후 저장
  • 키보드는 힘을 측정하지 못합니다. 오래 누를수록 페달이 깊어지는 방식(가속 2.5초, 브레이크 0.3에서 1.2초)
  • 둘 다 밟으면 브레이크 우선. 창 포커스를 잃으면 가속 차단 + 자동 제동, 브레이크를 한 번 밟으면 복귀

What this is

A browser stand-in for the Unity build. The gear rules, steering, creep, brakes, pedal calibration and HUD layout follow the C# code; motion uses a simple bicycle model with no tire slip or suspension. The ramp is drawn flat. Unity Play Mode is still the real test.
