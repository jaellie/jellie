# 빅그린베어의 모험 (Unity 6)

**처음부터 엔딩까지 플레이할 수 있는 전체 게임**이에요. 플레이 시간은 30~45분이에요.
이야기는 `big-green-bear/STORY.md`를 그대로 따라가요.

| 장 | 장소 | 내용 |
|---|---|---|
| 1장 벨플라워 겨울밤 | 광장 | 니니, 초록 방울, 11:47 시계, 비 |
| 2장 니니를 찾아서 | 광장 · 꽃가게 · 카페 · 공원 · 마을 입구 | 마을 사람 조사, 모순 수집, "누가 거짓말을 하고 있지?" |
| 3장 11:47 | 같은 장소들, 밤 | 시간 순서 맞추기, 지하 통로, "같이 가?" / "가." |
| 4장 이미 일어난 일 | 멈춰 버린 마을 | 두 번째 반전, "누가 빅그린베어를 죽였는가?" |
| 환한 방 + 에필로그 | 병원 · 다락방 | "그럼... 됐어요." 그리고 딸랑. |

모든 그림은 코드로 직접 그렸고, 소리도 전부 코드로 만들었어요.
폰트는 **프리텐다드**(SIL OFL, 무료로 게임에 넣어도 되는 라이선스)를 썼어요. **$0**이에요.

### 그림 스타일: 종이 조명 상자 (Paper-cut Lightbox)

게임 전체가 **뒤에서 불을 켠 종이 상자** 안에 있는 것처럼 보여요. 이 이야기 자체가 빅그린베어의 기억이고, 마지막에 어른 니니가 여는 것도 작은 상자예요.

- 장면마다 종이를 여러 장 겹쳐 세웠어요. **뒤쪽 종이는 밝고 비쳐 보이고, 앞쪽 종이는 어둡고 두꺼워요.** 이 밝기 차이로 깊이가 생겨요.
- 종이마다 결이 있고, 윗가장자리에는 빛이 닿고, 아래에는 그림자가 져요. 그리고 뒤의 종이에 그림자를 드리워요.
- 창문, 등불, 시계는 **종이를 오려 낸 구멍으로 빛이 새어 나오는 것**처럼 보여요.
- 장소마다 온도가 하나예요. 축제 밤은 파랑, 카페는 호박색, 공원은 청록, 마을 입구는 회청색, 지하 통로는 초록빛 검정, 병원은 하얀색, 다락방은 햇빛색이에요.
- 강한 색은 딱 두 가지예요. **빅그린베어의 초록**과 **니니의 노랑**.
- 캐릭터는 종이 인형처럼 몸, 팔, 머리 조각을 겹쳐 만들었어요.

스타일 문법은 [lemomo-ai/lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)의 "Paper-cut Lightbox"(MIT 라이선스)를 따랐어요. 간판 글씨는 Cormorant Garamond(SIL OFL)로 그림에 그려 넣었어요.

## 설치 / 업데이트

1. GitHub `jaellie/jellie`에서 브랜치를 **`claude/affectionate-bohr-cr0vb0`** 로 바꾸고 **Code → Download ZIP** 을 받아요.
2. 압축을 풀고 `big-green-bear-unity/Assets/BigGreenBear` 폴더를 찾아요.
3. 이 폴더를 Unity 프로젝트의 `Assets` 폴더에 **덮어쓰기**로 복사해요.
4. 장면에 이미 `SliceBootstrap`이 붙어 있다면 **바로 ▶** 누르면 돼요.
   - 처음이라면: 빈 GameObject를 만들고 → Add Component → `SliceBootstrap` → ▶

> 예전 시험판 파일(`slice.json`)이 프로젝트에 남아 있어도 괜찮아요. 이제 쓰지 않아요.

## 조작

| 키 | 동작 |
|---|---|
| `Enter` / `Space` / 클릭 | 다음 문장 |
| **장면 속 물건 클릭** / `1`~`9` | 선택 (빛 점이 있는 곳을 누르면 돼요). 할 일은 왼쪽(4개씩 한 줄), **→ 이동**은 맨 오른쪽 줄 |
| `N` / `Tab` / 오른쪽 아래 "수첩" | 수첩: 모은 단서 보기 |
| `L` | 한국어 ↔ English |
| `M` | 움직임 줄이기 |
| `Esc` | 수첩 닫기 / 게임 종료 |

**저장:** 장소에 들어갈 때마다 자동으로 저장돼요. 타이틀에서 **"이어하기"** 를 누르면 이어서 할 수 있어요.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 화면이 거의 검은색 | `SliceBootstrap`에서 **Use 2D Lights 체크 해제** |
| `Input` 관련 빨간 에러 | Edit → Project Settings → Player → **Active Input Handling** 을 `Both` 로 |
| 글자가 □로 나옴 | `Resources/BGB/Fonts/`에 프리텐다드 `.otf`가 있는지 확인 |
| 그 외 | Console의 빨간 줄과 `[BigGreenBear]` 노란 줄을 스크린샷으로 보내 주세요 |

## 구조

```
Assets/BigGreenBear/
├── Scripts/                 엔진 (이야기 내용 없음)
│   ├── SliceBootstrap.cs    ← 이것 하나만 붙이면 전부 조립
│   ├── SliceDirector.cs     이야기 진행, 이동, 수첩, 저장/이어하기
│   ├── Stage.cs             장소 만들기 (2.5D 레이어)
│   ├── Actor.cs             캐릭터 (표정, 깜빡임, 숨쉬기, 퇴장)
│   ├── CameraRig.cs         카메라 (장소별 시점, 깊이감, 16:9 고정)
│   ├── Atmosphere.cs        조명과 색 (축제, 비, 폭우, 카페, 통로, 멈춘 마을, 병원, 다락방)
│   ├── RainSystem.cs        비
│   ├── SliceAudio.cs        소리 (전부 코드로 합성)
│   ├── SliceUI.cs           대사, 선택지, 시계, 수첩, 물 차오름, 타이틀
│   └── SliceInput.cs        키보드/마우스
└── Resources/BGB/
    ├── Art/                 그림 (tools/ 로 다시 만들 수 있음)
    ├── Fonts/, FontsBold/   프리텐다드 + 라이선스
    └── Data/
        ├── story.json       ★ 이야기 전체 (314장면, 단서 33개, 한/영)
        └── layout.json      ★ 장소 8곳의 구도, 캐릭터 위치, 클릭할 물건, 조명
```

## 고치는 법 (만드는 사람용)

| 고치고 싶은 것 | 고칠 파일 | 그다음 실행 |
|---|---|---|
| 대사, 선택지, 단서 | `tools/build-story.py` | `python3 tools/build-story.py` (깨진 연결이 있으면 알려줘요) |
| 끝까지 갈 수 있는지 확인 | — | `python3 tools/playtest.py` (자동으로 300번 플레이) |
| 장소 구도, 캐릭터 위치 | `tools/build-layout.py` | `python3 tools/build-layout.py` |
| 구도 미리보기 (Unity 없이) | — | `node tools/simulate.js cafe cafe_changed` |
| 그림 (종이) | `tools/paper/cast.js` (캐릭터), `tools/paper/places.js` (장소), `tools/paper/ui.js` (화면 종이), `tools/paper/kit.js` (색, 공용 조각) | `node tools/render-art.js` (일부만: `node tools/render-art.js cafe bear`) |
