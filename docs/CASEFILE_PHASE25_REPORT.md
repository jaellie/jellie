# Case File Phase 2.5 제출물 (Thor → Loki)

범위: 이미 만든 네 화면의 사용성 개선과 photo_home 구현. 새 기능은 늘리지 않았다. 금지 사항(진행 플래그 변경, Q7, 정체 보드, 엔딩 변경, 새 스토리 사실, 저장 삭제·초기화)은 지켰다.

## 1. 변경 내용 (개선 전후 스크린샷은 함께 제출)

| 화면 | 개선 |

| 인물 | 초상 200px → 300x340px, 타일 크게, 이름·직함·본문 글자 확대. 진술, 관찰, 회상, 관련 증거가 아래로 늘어나는 레이아웃. 단계별 공개 유지 |

## 2. photo2 보강
- 기존 저장에서 `ar.photo`는 있는데 증거 `photo2`가 없는 경우 지급 경로가 막히던 문제를 막았다. 책상 조사 후 `photo2`가 없으면 핫스팟이 뜨고, `ar.photo`가 이미 있으면 반복 대사(`ar_re4`)로 지급한다.
- `photo2`가 이미 있으면 핫스팟이 사라지고 재지급하지 않는다. 3장 퀴즈 조건은 불변.

## 3. photo_home
- 3장 이후(`ch.3`) 오두막 액자 위치에 새 상호작용 `pphoto`. 새 대사 `pf_h`(기존 증거 설명문과 기존 대사 「그분은 항상 내 편이었는데」만 사용). `pro.frame`은 건드리지 않는다.
- 6장의 숨겨진 편지·장갑(`fr6`, `fin.on && fin.may2`)과 별개 이벤트. 6장에서는 `pphoto`가 나오지 않는다. 사진을 조사하지 않아도 엔딩 진행은 막히지 않는다.

## 5. 테스트 (60개 점검, 실패 0)
- S1~S10 회귀: 증거, 노트, 플래그가 변경 전과 동일, 오류 0.
- `S.qa`, `S.vis`가 없는 기존 저장: 모두 정상 동작(전 픽스처가 해당).
- 판단과 근거: 근거 표시가 판단을 설정하지 않음, 둘이 함께 저장, 재시작 후 유지, 새 단서 표시와 판단 불변.
- 방문 기록 오염: 디렉터 점프 4(회상 시작)에서 방앗간과 `past`가 방문 처리되지 않음, 회상 장면(`S.flash`)은 방문으로 기록하지 않음.
- photo2: (a) 책상 조사 전 숨김 (b) 조사 후 노출·1회 지급 (c) `ar.photo`만 있고 증거 없음 → 지급 가능 (d) 증거만 있고 `ar.photo` 없음 → 숨김, 재지급 없음.
- photo_home: 3장 이전 숨김, 이후 노출, 1회 지급, `pro.frame` 불변, 6장 프레임 상호작용은 그대로 `hidden`을 지급하고 `photo_home`은 지급하지 않음.
- 증거 묶음 개별 선택, 진술이 증거 탭에 없음, 옛 저장의 dormant 증거 표시, KO/EN 같은 묶음 ID, 증거 카드에 단순 종이 아이콘 없음.
- 지도 연결: 11:42 행 → 카페 핀 강조, 장소 없는 시간 → 핀 강조 없음과 안내문, 핀 클릭 → 장소 행 선택.
- 엔딩 A/B: 6장 마지막 선택에서 두 선택지 모두 피날레까지 도달(변경 전과 동일).
- 한국어·영어 화면: 4탭 스크린샷 확인. 질문 상세의 단서 카드에서 글자 겹침을 발견해 수정(클래스 이름 충돌).

## 6. 발견한 문제 (실제 플레이 검증 대신 합성 상태 점검 결과)
1. 기존 증거 설명문 중에는 답을 먼저 알려 주는 문장이 있다. 예: 「멈춘 시계」 설명 「에드워드가 죽은 시각은 아니다」는 Q2의 답을 암시한다. 설명문은 원문 보존 원칙으로 바꾸지 않았고, 질문 상세 화면의 단서 카드에서는 설명 요약을 빼고 이름만 보여 준다. 「자세히」를 누르면 원문이 보인다. 원문 수정 여부는 결정이 필요하다.
2. 지도 핀 좌표는 임시다. 마을 지형에 맞춘 배치가 필요하다.
3. 증거 아이콘은 제가 그린 임시 선 아이콘이다. 전용 일러스트가 있으면 교체한다.
4. 「새 게임부터 엔딩까지 사람이 직접 플레이한 검증」은 하지 않았다. 합성 저장과 스크립트 조작으로 점검했다.

## 7. 저장 필드
- `S.qa`: `{ q1: { v, n, b }, ... }` v=판단, n=판단 시점의 단서 수, b=근거로 표시한 증거 ID 목록.
- `S.vis`: 방문한 장소 `{ scene: 1 }`. 없는 저장에서는 플래그와 증거로 추정해 지도에 표시.
