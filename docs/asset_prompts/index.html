BGB2 Asset Prompts

Every image prompt below already ends with the transparent PNG line, so you can copy it as is. The list matches ASSET_REQUIREMENTS.md in the repo: only what is still left to make.

Sheets: every prompt with several items on one image also carries the spacing rule: at least 10 px (aim for 24 px) of transparent gap between items, nothing touching or overlapping. Audio prompts are the only ones without the PNG line, because they are not images. Tip: make the Mid layer first and attach it as a reference for the other layers so colours and lighting match.
