엔진 파일을 첨부한 새 lovesim-engine.js로 통째로 교체해줘. (지난 프롬프트 내용은 그대로 유지하고, 아래만 추가/수정)

━━ 1. 첫 화면 버튼 배경 ━━
- [START] / [이어하기 Continue] / [만든 사람에게 To Creator] 버튼들 뒤에 깔린 판(박스, 패널, 반투명 띠 등)을 전부 없애줘. 버튼을 감싸는 컨테이너는 background: transparent, 테두리·그림자 없음.
- 버튼 자체만 보이고, 그 뒤로는 인생길 배경(하늘·길·걷는 나)이 그대로 보이게.

━━ 2. 운명의 상대가 사는 곳 ━━
- 운명의 상대 칸에 "그 사람은 지금 어디 살고 있나요?" 도시 고르기를 항상 보여줘 (지금은 이 칸이 안 보여).
  · 라벨/안내: LoveSim.fatedOptions(lang).homeQuestion / .homeHint
  · 기본값 = 내가 고른 "현재 어디 살고 있나요?" 도시.
  · 예전의 [같은 도시 / 다른 도시 / 해외] 고르기 + 도시 칸은 이걸로 대체 (지워도 돼). 같은 도시인지 장거리인지 해외인지는 엔진이 도시를 보고 알아서 정해.
  · 고른 도시의 id를 createGame({ ..., fated: { ..., city: "<id>" } }) 로 넘기기.
- 순서: 이름 → 지금 어떤 사이? (+날짜) → 그 사람은 지금 어디 살고 있나요? → 직업 → 생일 → 태어난 곳 → MBTI

━━ 3. 도시 입력칸 = 자동완성 + 반드시 골라야 확정 (모든 도시 칸) ━━
태어난 곳, 현재 사는 곳, 상대가 사는 곳, 상대가 태어난 곳 전부 이렇게:
- 글자를 치면 바로 아래에 후보 목록: LoveSim.searchPlaces(입력한 글자, lang) → [{ id, name, country, countryName }] (최대 8개). 각 줄에 "여수 · 한국" 처럼 표시.
- 목록에서 한 줄을 "눌러야만" 확정돼. 확정되면 칸에 그 도시 이름을 넣고 작은 ✓ 표시. 넘길 값은 그 id.
- 친 글자만으로는 절대 확정하지 마 (모바일 키보드의 완료/엔터, 다음 칸으로 넘어가기, 바깥 탭 포함). 예: "여수수"라고 치면 후보가 없음 → 그대로 넘어가면 안 돼.
  · 후보가 없으면 목록 자리에 "찾는 도시가 없어요. 가장 가까운 도시를 골라 주세요" (영어: "No match — pick the nearest city").
  · 확정 안 된 채로 칸을 벗어나면 마지막으로 확정했던 도시로 되돌리고, 확정된 적이 없으면 칸 테두리를 빨갛게 + [다음]/[새 게임] 버튼 비활성.
- 모바일에서 후보 목록이 키보드에 가리지 않게 칸 바로 아래에, 한 줄 높이 44px 이상 (손가락으로 누르기 쉽게).
