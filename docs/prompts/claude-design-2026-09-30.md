# Claude Design에 붙여넣을 프롬프트 (2026-09-30 · 인생길 화면 + 운명의 상대 + 무드 라인)

```
엔진 파일을 첨부한 새 lovesim-engine.js로 통째로 교체해줘. (지난 프롬프트 내용 중 "방 화면(쿼터뷰)으로 플레이" 부분은 아래로 바뀌어. 나머지는 유지)

1. 시작 화면
   - 첫 화면 = 언어 고르기 [한국어] [English] 버튼 두 개.
   - 고르면 설정 화면을 const d = LoveSim.setupDefaults(lang) 값으로 채워서 열기:
     이름 d.name ("제이" / "Jae"), 생년월일 d.birth (1997. 9. 28), MBTI d.mbti, 태어난 곳 d.birthplace …
   - createGame({ ..., lang }) 로 넘기기.

2. 운명의 상대 설정 — const o = LoveSim.fatedOptions(lang)
   - 질문 o.statusQuestion ("지금 두 사람, 사귀고 있나요?") + 선택지 o.statuses (3개, 버튼이나 드롭다운):
     · "응, 사귀는 중이야" (dating) → 연인인 상태로 시작
     · "아니, 썸 타는 중" (talking) → 썸부터: 새벽 카톡, 이거 데이트야?, 질투, 첫 고백까지
     · "아니, 아직 서로 몰라" (stranger) → 첫 만남부터
   - "상대는 어디서 살까요?" → o.lives (같은 동네 / 다른 도시 / 다른 나라). 이름 옆에 작은 설명 hint도 보여줘.
     다른 도시/다른 나라면 "그 사람이 사는 도시" 입력칸 (태어난 곳과 같은 자동완성 목록 사용).
   - "상대의 직업은?" → o.jobs (28개) + 맨 위에 "운명에 맡기기".
   - 넘기기: fated: { name, gender, mbti, birth, birthplace, status, from, city, job }
   - 이제 이 값들이 진짜로 스토리를 바꿔: 어디서/어떻게 만나는지(바리스타면 단골 카페, 의사면 응급실, 다른 나라면 언어교환 앱에서 시차 넘어서), 장거리 연애(영상통화 → 만나러 가기 → 누가 옮길까), 같이 살면 직업별 이벤트(야간 근무, 비행, 수입 0원인 달…).

3. 플레이 화면 = 인생길 (가장 큰 변경)
   - 쿼터뷰 방 화면은 플레이 중엔 안 써. 대신 2D 픽셀 "길": 뒷모습의 내가 화면 아래쪽에서 지평선(위에서 1/3 지점)으로 뻗은 길을 계속 걸어가.
     길 양옆에 나무/건물/가로등이 멀리서 다가와 옆으로 지나가고, 가운데 점선이 아래로 흘러. (첨부한 스케치 느낌 그대로)
   - 매 250ms 정도 const r = game.road() 읽기:
     · r.walkers: 같이 걷는 사람들 (slot 순서대로 왼→오, 다 뒷모습). role: me / partner / kid / baby / pet
       - holds 가 있으면 둘이 손잡고 걷기, carriedBy 면 그 사람이 안고 있는 아기(또는 유모차), pace 로 걸음 속도(나이 들면 느리게, 반려동물은 총총).
       - 연인이 생기면 옆에서 같이 걷기 시작해. (장거리 연애 중엔 안 보임 → 같이 살게 되면 나타남.) 아이, 반려동물도 합류.
     · r.backdrop: theme (city 도시 / town 작은 동네 / seaside 바닷가 / countryside 노년의 시골 들판 / abroad 외국 도시 / travel 여행지), season (나무 색: 봄 벚꽃, 여름 초록, 가을 단풍, 겨울 흰색), timeOfDay (하늘색: 아침/낮/저녁 노을/밤), weather (비·눈 효과).
       천천히 바뀌기만 하고 화면이 끊기지 않게.
     · r.landmark: 오늘 가는 곳 (카페, 회사, 병원, 예식장…). 바뀌면 그 이름 간판이 달린 건물이 길 저편에서 다가와 옆으로 지나가게.
     · r.walking === false (팝업 열림) 이면 스크롤 멈추고 다들 제자리에 서 있기.
   - 캐릭터 이름표 없음. 화면 아래 버튼(나가기, 집안일 등) 전부 삭제 — 하루는 알아서 흘러가.
   - 장소 표시는 "📍 장소 · 도시"만 작게 (시간 X).
   - 30배속에서도 정신없지 않게: 길은 컷 없이 이어지고, 하루가 끝날 때("시간이 흐른다…")만 페이드.

4. 맨 위 한 줄 = 오늘의 기분 (로그 X, 시간 X)
   - advance() 에서 오는 {kind:"mood", text} 를 그대로 보여줘 (하루에 한 번). game.mood() 로도 읽을 수 있어.
     예) "(요즘 자꾸 해외로 나가고 싶다.)", "(남편이 요즘 휴대폰을 엎어 둔다. 뭔가 쎄하다.)" — 사주·점성술과 앞으로 올 일을 암시하는 문장.
   - 예전의 "하윤과 처음으로 제대로 대화했다" 같은 로그와 시각 표시는 전부 삭제. {kind:"log"} 는 더 이상 안 와.
   - {kind:"enter"} 는 "오늘 장소가 바뀜" 신호일 뿐 → 로그에 쓰지 말고 길가 간판(landmark)으로만.

5. 팝업 (지금처럼: 제목 배너 + 사진 + 대사 + 선택지)
   - 항상 플레이 화면 정가운데.
   - 사진 = popup.scene (위에서 본 방 그림, 기존처럼 너비에 맞춰 축소 + focus 로 잘라내기).
   - popup.reading 이 있으면 (운명의 갈림길) 제목 바로 아래에 작은 글씨로: "🔮 사주: 도화 · 천간합 / 점성술: 목성 5하우스 / 상대: 역마" — 사주·점성술이 이야기를 움직이고 있다는 게 보이게.
   - 결과 대사의 말하는 사람은 결과의 name 을 그대로 (예: 프러포즈에 "좀 더 시간이 필요해"라고 하면, "…그래. 그런데 난 오래 기다리진 못할 것 같아."는 연인 이름으로 나와).
   - 친구 결혼식 청첩장, 형제 결혼식, 조카 탄생, 친구 부고도 이제 팝업으로 와 (예: "친구 하윤에게서 연락이 왔다. 나 결혼해! 청첩장 모임 올 거지?"). 다른 팝업과 똑같이 처리.

6. 알림(toast)은 지금처럼. 하루 끝/큰 팝업 열릴 때 비우기 유지.
```
