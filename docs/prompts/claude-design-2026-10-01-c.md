```
엔진 파일을 첨부한 새 lovesim-engine.js로 통째로 교체해줘. (지난 프롬프트 내용은 그대로 유지하고, 아래만 추가/수정)

━━ 1. 게임의 시작과 끝 (가장 큰 변경) ━━
이제 게임은 "2026년 ~ 내가 죽을 때까지"가 아니라 "운명의 상대와 처음 만나는 날(또는 지금 사귀는/썸 타는 상태) ~ 그 관계가 끝나는 날"까지야.
결혼해서 끝까지 함께하면 엔딩은 나의 죽음.

- 시작: 모르는 사이/아는 사이로 시작하면 만나기 전 몇 년은 엔진이 알아서 건너뛰어. 첫 플레이 날 = 만나는 날.
  · game.s.day.prologue 가 있으면(예: "그 사람을 만나기까지, 7년이 흘렀다.") 첫 화면 전에 검은 화면에 이 문장을 가운데 2초 정도 보여주고 페이드아웃 → 인생길.
- 끝: endDay() 가 over: true 를 주면 게임 끝. const e = game.ending() 사용:
  · e.reason: "missed"(끝내 엇갈림) / "breakup"(이별) / "divorce"(이혼) / "theyDied"(상대가 먼저 떠남) / "iDied"(나의 죽음)
  · e.title (예: "끝내 엇갈린 인연", "우리의 계절은 여기까지", "각자의 길로", "먼저 떠난 당신", "함께 늙어간 인생")
  · e.story (한두 문장), e.together = { from, to, years, married }
  · 엔딩 화면: 검은 배경 페이드 → 맨 위 e.title (노란색, 크게) → e.story → game.memorial().epitaph (예: "제이 ♥ 정 · 2033 – 2041") → memorial().lines 한 줄씩 → [새 인생].
  · reason 이 "iDied" 일 때만 지금의 추모(죽음) 분위기 그대로, 나머지는 살아 있는 채로 끝나는 엔딩이라 같은 화면이지만 묘비 느낌 대신 담담하게.

━━ 2. 첫 화면 (언어 고르기) ━━
- 배경 = 플레이 화면과 같은 인생길. 뒷모습의 내가 길 위를 뚜벅뚜벅 계속 걸어가고 점선이 아래로 흘러가는 화면. (하늘/풀/길 + 걷는 나)
- 로고는 이 화면에만. 위에서 "두두둥" 떨어지며 등장: 위에서 떨어져 → 살짝 튕겼다가(아래로 8% 넘어갔다 돌아옴) → 자리 잡기. 0.9초 정도.
- 설정 화면에서는 로고 삭제.

━━ 3. 설정 화면 ━━
- 내 직업 고르기 추가 (MBTI 아래): const mj = LoveSim.myJobOptions(lang) → 라벨 mj.question ("나의 직업은?"), 선택지 mj.jobs (45개: 회사원, 대학생, 무직, 취업준비생, 프리랜서, 간호사, 약사, 수의사, 웹툰 작가, 댄서, 파일럿 …). 고른 id 를 createGame({ ..., job }) 로 넘기기.
- 상대 직업 목록도 같은 45개로 늘었어 (fatedOptions(lang).jobs 그대로).
- 설정 순서를 이렇게 바꿔줘 (외모 고르기는 각자 정보를 다 입력한 "뒤"에):
  1) 나: 이름 → 생년월일(+태어난 시간) → 태어난 곳 → 성별 / 좋아하는 사람 → MBTI → 나의 직업 → 가족
  2) [나의 모습] 내 캐릭터 얼굴·머리·옷 고르기
  3) 운명의 상대: 이름 → 지금 사귀고 있나요? → 어디서 사나요? (+도시) → 직업 → 생일 → 태어난 곳 → MBTI
  4) [그 사람의 모습] 상대 캐릭터 얼굴·머리·옷 고르기 ← 맨 마지막
  5) ▶ 새 게임

━━ 4. 캐릭터 디자인 수정 ━━
- 여자 웨이브 머리: 지금은 그냥 부스스한 긴 머리처럼 보여. 굵고 또렷한 S자 물결이 2~3번 보이게, 끝은 동글게 말리게 다시 그려줘.
- 귀걸이(액세서리): 귀걸이로 안 보여. 귀 위치(얼굴 옆, 머리카락 바깥)에 반짝이는 동그라미/링 + 아래로 늘어진 작은 포인트(밝은 금색 1~2픽셀 하이라이트)로.
- 모자(액세서리): 모자로 안 보여. 앞으로 튀어나온 챙이 확실히 보이는 볼캡으로 (챙은 머리보다 진한 색, 머리 위 돔 + 앞 챙).
- 남자 삭발 머리: 탈모처럼 보이고 두상이 너무 커. 두상 크기는 다른 머리 스타일과 같게 줄이고, 머리 전체를 짧은 머리색으로 고르게 덮어서 (살색 정수리 X) 짧게 민 버즈컷처럼.
- 머리 색: 어두운 계열이 너무 많아 → 어두운 색은 3개만 (검정, 진갈색, 밝은 갈색). 그리고 금발, 빨간 머리, 주황 머리, 초록 머리, 파란 머리 추가. 총 8개.
- 흰머리: 나이 들면 원래 머리색 위에 회색을 투명도 낮게(50대 15%, 60대 30%, 75세 이상 45% 정도) 덮어서 "흰머리가 많이 난" 느낌으로. 지금처럼 갑자기 새하얀/회색으로 바뀌어 대비가 심한 건 X.

━━ 5. 팝업 ━━
- 이벤트 팝업 맨 위 카테고리 이름 띠([프러포즈] [부고] [고백] …)를 검정 대신 남색으로: 위→아래 그라데이션 #34477f → #1f2c5c, 테두리 #141c3d. 하얀 글씨는 그대로.
- 큰 순간은 이제 팝업 4개가 연달아 와 (제목에 "(1/4)", "(2/4)", "(3/4)", "(4/4)"). 따로 처리할 건 없어 — 결과를 보여주고 ▼ 누르면 다음 advance()에서 바로 다음 팝업이 와.
  · 고백, 첫 키스, 프러포즈: 1) 상대의 행동 2) 내 속마음 3) 결정적 순간 직전 4) 클라이맥스. 상대·나의 MBTI에 따라 장면과 선택지가 달라져.

━━ 6. 메시지(토스트) ━━
- 큰따옴표 없이 "보낸 사람: 내용" 그대로. 예) 아빠: 밥은 잘 먹고 다니냐?   (지금처럼 아빠: "밥은 잘 먹고 다니냐?" 는 X)
- 등장할 때도 위에서 "두두둥" 떨어지듯이 (로고와 같은 애니메이션, 0.55초).

━━ 7. 인생길 ━━
- 화면 아래 "📍 공원 · 한국 · 제주" 장소 표시 글씨를 더 크게 (지금의 1.3배 이상, 약 15px).
- 바닷가 도시(부산, 제주, 강릉 …): game.road().backdrop.sea === "right" 이면 바다는 오른쪽.
  · 큰 건물(회사, 병원, 예식장, 가게 등)은 항상 왼쪽 땅 위에. 오른쪽에는 작은 집(빨간 지붕 작은 주택)만, 그 너머가 바다. 큰 건물이 바다 위에 떠 있는 일 없게.
  · 오늘 가는 장소: road().landmark.side ("left"/"right") 쪽에, landmark.size ("big"/"small") 크기로 그리면 돼. backdrop.sides = { left, right } 는 각 길가에 늘어설 것 (buildings / houses).

━━ 8. 참고 (엔진에서 고친 것 — UI 변경 없음) ━━
- NPC 이름: 한국어판은 전부 한글 이름(외국에 살거나 여행 중이면 그 나라 이름을 한글로: 하루토, 카미유), 영어판은 전부 영어 이름(서준 → Noah). 상대 성별과 이름이 항상 맞아 (남자 친구가 "예린"인 일 없음). 엔진이 준 이름 그대로 쓰기.
- 직업 표시: "회사원 L6" → 그냥 "회사원". 고른 직업이 그대로 나와 (간호사, 대학생, 무직 …).
- 부모님의 죽음은 이제 3일에 걸친 이야기: 마지막 밤(병원, 마지막 말) → 부고(장례식장) → 빈자리(몇 달 뒤 집). 일반 부고와 다르게 더 슬프고 길게.
- 관계를 끝낼 수 있는 일(이별, 이혼, 외도)은 화면 밖에서 저절로 일어나지 않고, 항상 플레이하는 날 팝업으로 와.
```
