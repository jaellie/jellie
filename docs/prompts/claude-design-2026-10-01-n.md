# Claude Design에 붙여넣을 프롬프트 (2026-10-01 · 14차 = k + l + m + 새 요청 전부 합본)

첨부: 새 lovesim-engine.js + bg-pack.zip (안의 bg 폴더 PNG 37장 전부)

```
엔진 파일을 첨부한 새 lovesim-engine.js로 통째로 교체해줘. 반드시 기존 엔진 파일을 지우고 이 파일로 바꿔야 해. 지난 프롬프트 내용은 유지하고, 아래를 전부 반영해줘. 다 끝나면 항목별로 반영했는지 하나씩 확인해줘.

━━ 0. 엔진 버전 확인 ━━
- Letter from Creator 페이지 맨 아래에 아주 작은 회색 글씨로 "engine " + LoveSim.ENGINE_VERSION. 이번 엔진이면 "engine 2026-10-01.n".
- 시작할 때 console.log("LoveSim", LoveSim.ENGINE_VERSION).

━━ 1. 첫 화면 ━━
- 인생길 배경이 화면 전체를 위에서 아래까지 꽉 채우게: 하늘은 화면 맨 위 끝에서 시작, 풀과 길은 화면 맨 아래 끝까지 (버튼 뒤로도). 위아래 하늘색 띠/여백 X. 배경 컨테이너: position absolute; inset 0.
- [START], [이어하기 Continue], [Letter from Creator] 를 감싸는 모든 부모 요소의 배경 제거: background: none; border: none; box-shadow: none; backdrop-filter: none. 크림색 판이 한 픽셀도 보이면 안 돼. 버튼 색은 그대로 (START 핑크, 아래 둘 secondary).

━━ 2. 상단바 = 예전 스타일로 ━━
- 어두운 바(거의 검정에 가까운 남보라) 위에 두 줄, 왼쪽 정렬:
  · 윗줄: "33세 · 2031.05.03 (토)" — 흰색, 굵게, 조금 크게. (영어: "33 yrs · 2031.05.03 (Sat)")
  · 아랫줄 왼쪽: "사장님 · 성민과 연애 중" — 작은 회색 글씨, 가운뎃점(·)으로 구분.
  · 아랫줄 오른쪽 끝: 돈 "₩78,992,232" — 노란색, 오른쪽 정렬.
  · 바 맨 아래에 얇은 핑크 진행 바 (하루 진행도).
- 가운데 정렬 X. 위 모양 그대로.

━━ 3. 글씨 크기 ━━
- 괄호 내레이션 글씨("(요즘 되는 일이 없다…)")를 작아지기 전 원래 크기로 되돌리고, 아래 장소 표시("📍 공원 · 한국 · 서울")를 그 크기와 똑같이.

━━ 4. 하늘 ━━
- 하늘 그라데이션은 하늘 레이어에만 (화면 맨 위 → 지평선). 땅까지 늘어나면 X.
- road().backdrop.sky.gradient 의 4색을 0% / 33% / 66% / 100% 에 고정, linear-gradient(to bottom). 레이어 높이 고정, background-size 100% 100%.
- 색이 바뀔 땐 하늘 레이어 2장을 2초 크로스페이드 (그라데이션을 transition 하지 말기).

━━ 5. 나와 상대가 걷는 간격 ━━
- me 와 partner(또는 holds: "me")는 한 쌍으로 길 가운데에 나란히: 상대 왼쪽 끝 = 내 오른쪽 끝 + 캐릭터 폭의 10%. 같은 y. slot 으로 멀리 띄우지 말기. apart: true 여도 간격 같고 상대만 55% 투명.

━━ 6. 이벤트 팝업 / 추억 카드 사진 = 그려 둔 배경 그림 ━━
- 첨부한 bg-pack.zip 의 PNG 37장을 bg/ 폴더에 (같은 이름은 덮어쓰기).
- 모든 큰 팝업(4장짜리 고백·첫 키스·프러포즈 시퀀스 포함, occasion·event 포함)과 추억 카드에서: scene.photo 가 있으면 방을 코드로 그리지 말고 그 그림을 배경으로: background: url(<photo>) center bottom / cover no-repeat. 소품·바닥·벽 그리기 X.
- 사람은 scene.photoCast 에 있는 사람만 그려 (actor.who 목록, 보통 나 + 상대 2명, 혼자면 나만). 나머지 actors 는 그리지 마 (일렬로 늘어놓지 말 것).
  · 그 1~2명을 사진 칸 가로 가운데에 나란히, 발끝 = 사진 칸 높이의 88%, 둘 사이 간격 = 캐릭터 폭의 10%, 캐릭터 크기 = 사진 칸 높이의 약 35%. 머리가 칸 밖으로 잘리지 않게.
- photo 가 없으면 지금처럼 코드로 그린 방.

━━ 7. "시간이 흐른다…" 화면 배경 ━━
- endDay() 결과에 photo 가 와 (예: "bg/airplane_cabin.png"). 시간이 흐르는 화면(검은 화면 대신) 뒤에 이 그림을 꽉 채워 깔고, 그 위에 반투명 어두운 막(rgba(0,0,0,0.45))을 덮은 다음 글씨를 올려줘.
  · 여행을 다녀왔으면 반드시 그 장소 그림 (파리 → 에펠탑, 도쿄 → 도쿄 거리, 바닷가 → 바다, 그림 없는 도시 → 공항 입국장), 비행기 → 비행기 안, 이사 → 공항.
  · 그 밖엔 계절에 맞는 평화로운 그림이 랜덤으로 와. 엔진 값 그대로 쓰면 돼.
- 추억 카드가 있으면 카드마다 card.scene.photo 로 (6번과 같은 방식).
```
