# Claude Design에 붙여넣을 프롬프트 (2026-09-27 · 3차: 장면을 화면 가득)

```
엔진 파일을 첨부한 새 lovesim-engine.js로 통째로 교체해줘. (지난 프롬프트 내용은 그대로 유지하고, 아래만 추가/수정)

목표: 게임 화면에서 배경과 캐릭터가 화면 절반이 아니라 "화면 전체"를 채우게 (카이로소프트 게임처럼).

1. 플레이 화면 레이아웃
   - 맨 위 HUD → 그 아래 로그 한 줄 → 그 아래 "전부"가 장면(배경+캐릭터). 폰 맨 아래 끝까지.
   - 장면 아래에 있던 일기/로그 상자는 삭제.
   - 장소 표시(📍 장소 · 도시 · 시간)는 장면 위, 왼쪽 위 구석에 겹쳐서 작게.
   - 알림(toast)은 지금처럼 로그 줄 아래에서 내려오게 (장면 위에 겹쳐짐).

2. 장면 = 세로로 긴 방 하나 (엔진이 좌표를 다 줌)
   - const sc = game.scene(); 기준 상자는 sc.stage.ref = [360, 642] (세로).
   - 실제 장면 영역 W×H 에 맞춰 균등 확대: k = Math.max(W/360, H/642), 가운데 정렬, 넘치는 부분은 잘림 (#scene { overflow:hidden }).
     → 어떤 폰 비율이든 빈 공간 없이 꽉 참. 걸어다니는 바닥은 여유를 두고 있어서 사람이 잘리지는 않아.
   - 벽과 바닥 (값은 모두 기준 상자에 대한 비율 0~1):
     · 뒤쪽 벽 두 개가 V자로 만남: 꼭짓점 sc.stage.corner (가운데, y≈0.17) → 양쪽 끝 sc.stage.leftBase / sc.stage.rightBase (화면 좌우 끝, y≈0.31).
     · V 위쪽 = 벽 (왼쪽 벽을 조금 더 어둡게), V 아래 전부 = 바닥 (화면 맨 아래까지).
     · 바닥은 마름모 타일: 한 칸 크기 sc.stage.tile.w × sc.stage.tile.h (기준 상자에서 72×36px), 타일 꼭짓점 하나가 corner에 오게.
   - 기존 ROOMS 페인터(카페, 사무실, 집…)를 이 360×642 세로 방에 맞게 다시 그려줘:
     창문·액자·선반은 벽에, 카운터·테이블·화분은 바닥 가장자리/벽 쪽에. 바닥 가운데는 비워둬 (사람들이 방 전체를 걸어다녀).

3. 캐릭터 위치 — 엔진이 준 좌표 그대로
   - 각 actor 의 발 위치 = (actor.x × 360 × k, actor.y × 642 × k) (+ 가운데 정렬 오프셋).
   - 스프라이트 키 ≈ sc.stage.spriteHeight × 642 × k (기준 상자에서 약 64px, 화면 높이의 1/10). 아이(kid)는 0.65배, 아기(baby)는 0.5배.
   - zIndex = actor.z (앞사람이 뒷사람 위에).
   - 예전 X(i,j) / Y(i,j) 격자 계산 코드는 전부 삭제. (spot 은 참고용으로만 남아 있어)
   - x, y 가 0~1 밖이면 화면 가장자리 밖으로 걸어나가는 중이야 → 그냥 그 위치에 그리면 자연스럽게 잘려 보여.

4. 걷기 (지금 방식 유지, 좌표만 바뀜)
   - 500ms 마다 game.wander() → 새 actor.x / actor.y 로 480ms 동안 선형 이동.
   - walking → 걷기 프레임, facing 이 SW 또는 NW → 좌우 반전, offscreen → 숨김(나중에 다시 들어옴).
   - actor 요소는 who 로 유지해서 매 프레임 새로 만들지 말기 (그래야 움직임이 이어져).
   - 이제 사람들이 방 끝에서 끝까지 가로질러 걷고, 왼쪽/오른쪽/아래 가장자리로 나갔다 들어와.

5. 작은 그림 (큰 사건 팝업의 그림, "시간이 흐른다…" 기억 카드)
   - 같은 장면을 그대로 그리되, 그림 상자의 "너비"에 맞춰 축소 (k = 상자너비 / 360).
   - 세로는 사람들이 있는 구간 sc.focus = { top, bottom } (0~1) 을 가운데로 잘라내기:
     전체높이 = 642 × k
     offset = clamp(((focus.top + focus.bottom) / 2) × 전체높이 − 상자높이 / 2, 0, 전체높이 − 상자높이)
     → 안쪽 요소를 top: -offset 로 올려서 보여줘. (카드: card.scene.focus, 팝업: popup.scene.focus)

6. 알림 정리 (버그 수정)
   - 하루가 끝날 때(game.endDay() 부를 때)와 큰 팝업(popup.big === true)이 열릴 때 알림(toast) 목록을 싹 비워줘.
     (전날 온 동료 카톡 "팀장님 오늘 기분 좋으심 ㅋㅋ" 이 다음 날 부고 팝업 위에 남아 있던 문제)

7. 온라인 장소 (커뮤니티, 인스타그램, 소개팅 앱, 언어교환 앱)
   - scene.online === true 면 "집에서 휴대폰 하는 중"이야. 배경은 집(roomKey "home"), 집에 있는 가족(저녁/주말의 배우자, 아이, 반려동물)만 있고, 온라인 상대는 방에 없어.
   - 나(role "me")는 휴대폰을 들고 있게 그려줘 (손에 작은 폰 스프라이트나 📱 말풍선). 큰 사건 팝업 그림(예: 커뮤니티의 "표절 의혹")도 똑같이.
   - (전에는 온라인 장소가 사람도 배경도 없는 까만 화면이었어 — 이제 엔진이 채워줘.)

8. 겹침 순서 (그대로 유지)
   - #scene { position:relative; isolation:isolate; overflow:hidden } — actor.z 가 커도 캐릭터가 팝업 위로 올라오지 않게.

9. (선택) 픽셀아트 선명하게
   - 장면을 내부 해상도 180×321 <canvas> 에 그리고 CSS 로 ×2 (image-rendering: pixelated), 그 캔버스를 위의 k 로 cover 확대.
   - 배경 그림이 생기면 크기는 360×642 (또는 180×321 을 ×2). 벽 V선·바닥 선은 위 2번과 같게.
```
