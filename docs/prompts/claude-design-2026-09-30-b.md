# Claude Design에 붙여넣을 프롬프트 (2026-09-30 · 2차)

```
엔진 파일을 첨부한 새 lovesim-engine.js로 통째로 교체해줘. (지난 프롬프트 내용은 그대로 유지하고, 아래만 추가/수정)

1. 팝업 위치 (버그) — 지금 정가운데보다 살짝 아래에 떠
   - 팝업은 "폰 화면 전체"(HUD 포함한 앱 프레임 전체)의 정가운데에 둬. HUD 아래 영역 기준으로 가운데 맞추지 말고.
     #popupWrap { position:absolute; inset:0 } (프레임 전체 덮기)
     #popup { position:absolute; left:50%; top:50%; transform:translate(-50%,-50%); margin:0 }
   - 팝업이 길어지면 위치를 옮기지 말고, 사진 높이를 줄이거나 팝업 안쪽을 스크롤.

2. 게임 끝 → [새 인생] 버튼
   - 누르면 완전히 첫 화면(언어 고르기 [한국어 / English])으로 돌아가게. 이전 게임 상태, 입력값 전부 초기화.

3. 캐릭터 성별/외모는 엔진이 주는 값 그대로
   - 인생길 walkers[].gender, 팝업 popup.gender, 사진/카드의 actors[].gender 를 꼭 사용해서 몸/머리 스프라이트를 골라줘.
     절대 이름이나 기본값으로 추측하지 말기. (여자 주인공 + 남자를 좋아함 → 연인은 항상 "M")
   - 이혼·이별 뒤의 추억 카드에도 이제 연인 gender 가 항상 들어가.

4. 새 연인이 생기면 같이 걷기
   - game.road().walkers 에 role "partner" 가 있으면 내 옆에서 손잡고 걷게 (운명의 상대든 새로 만난 사람이든 똑같이).
   - 장거리 연애 중에는 walkers 에 연인이 없어 → 그때는 혼자 걷는 게 맞아. 같이 살게 되면 다시 나타나.
   - walkers 는 250ms 마다 새로 읽어서 사람이 들어오고 나가는 걸 반영해줘 (이름표 없이).

5. 도시마다 다른 스카이라인 (Subway Surfers 월드투어 느낌)
   - game.road().backdrop.skyline = { id, name, landmarks[], street[], palette{sky,buildings,accent}, generic }
     · 주요 도시 56곳: 서울(N서울타워·롯데월드타워·한강 다리 / 한글 네온, 편의점, 포장마차), 부산, 제주, 도쿄(도쿄타워·스카이트리 / 자판기, 전선, 노렌),
       파리(에펠탑 / 카페 테라스, 발코니), 뉴욕(엠파이어 스테이트·자유의 여신상 / 노란 택시, 소화전), 밴쿠버, 싱가포르, 방콕, 런던 …
     · 목록에 없는 곳은 generic: 한국 도시(아파트 단지, 치킨집 간판) 또는 일반 외국 도시.
   - landmarks = 지평선 위 실루엣 (도시가 바뀌면 교체), street = 길가에 가끔 지나가는 소품/간판, palette = 하늘·건물·포인트 색.
   - 사는 곳(이사/해외 이주)이나 여행지에 따라 자동으로 바뀌어.

6. 시작 연도
   - 이제 게임은 2026년, 주인공 생일에 시작해 (1997년생이면 2026.09 · 29세). 18세 미만이면 18세부터.

7. 영어 버전
   - 엔진이 영어일 때 내보내는 모든 글자는 영어만 (한국 이름은 로마자: 재윤 → Jaeyun, 할머니 → Grandma, 오빠 민수 → my older brother Minsu).
     UI 쪽 고정 문구(버튼, 라벨, "시간이 흐른다…" 등)도 영어로 준비해줘.

8. 참고 (엔진에서 고친 것 — UI 변경 없음)
   - 장거리 연애 중엔 "○○와 공원 데이트" 같은 대면 약속이 안 떠 (대신 "영상통화 데이트", "택배 싸기").
   - 무드 라인이 상황과 안 맞던 것 수정 (연애 중 "설레고 싶다. 누구라도", 결혼했는데 "주변에서 결혼한다…" 안 나옴).
   - 해외에 사는데 역마 이벤트가 뜨면: "한국으로 돌아간다 / 이 나라의 다른 도시로 / 여기 남는다".
   - 퇴사/자영업 뒤엔 동료·팀장 메시지 안 옴.
```
