# Claude Design에 붙여넣을 프롬프트 (2026-10-01 · 5차 · 하늘)

```
엔진 파일을 첨부한 새 lovesim-engine.js로 통째로 교체해줘. (지난 프롬프트 내용은 그대로 유지하고, 아래만 추가)

━━ 인생길 하늘을 더 다이나믹하게 ━━
지금은 시간대별로 하늘색이 한 가지로 툭 바뀌어. 이제 game.road().backdrop.sky 를 써서 하루 내내 부드럽게 변하는 그라데이션 하늘로:

- sky.gradient = [맨 위, 위쪽, 아래쪽, 지평선] 4색 → 지평선 위 하늘 영역 전체를 위→아래 linear-gradient 로. 250ms 마다 새 값이 오니까 1~2초 transition 으로 부드럽게.
  · 새벽: 남색 → 보라 → 분홍 → 복숭아빛
  · 아침: 맑은 하늘색 → 지평선은 연한 살구빛
  · 오후: 진한 파랑 → 하얀 지평선
  · 노을: 남보라 → 자주 → 주홍 → 금빛 (완전 예쁘게!)
  · 해 질 녘(dusk): 짙은 남색 → 보라 → 어두운 장밋빛
  · 밤: 아주 짙은 남색
  · 비/눈 오는 날은 엔진이 알아서 회색빛으로 칙칙하게 섞어 줘.
- sky.phase = "dawn" | "morning" | "afternoon" | "sunset" | "dusk" | "night" (필요하면 길/건물 그늘 톤에 사용)
- sky.sun = { x, y, color, glow } — 해 (x, y = 하늘 영역 안의 비율, y 0 = 맨 위, 1 = 지평선). 아침 왼쪽에서 떠서 정오에 높이, 저녁 오른쪽으로 짐. glow 로 해 주변 빛 번짐. 노을 땐 주황빛 큰 해.
- sky.moon = { x, y } — 밤엔 초승달 (같은 방식으로 이동).
- sky.stars = 0~1 — 별 밝기. 하늘에 작은 픽셀 별 40~50개를 뿌려 두고 각자 다른 박자로 반짝반짝 (opacity 0.25 ↔ 1), 전체 투명도 = stars.
- sky.clouds = 그 시간대 구름 색 (아침 흰색, 노을 땐 분홍·주홍, 밤엔 어두운 남색).
- sky.flyers = { birds, plane, shootingStar } — "1초당 등장 확률". 매 프레임 확률로 굴려서 가끔 하늘을 가로지르게:
  · birds (아침): 작은 새 떼 V자가 왼→오른쪽으로 날아감 (8~10초)
  · plane (오후): 작은 비행기가 하얀 비행기구름을 끌며 오른→왼쪽으로 (14초쯤)
  · shootingStar (맑은 밤): 별똥별이 사선으로 슝 (1초)
  · 한 번에 최대 2개까지만. 비/눈 오는 날은 0으로 와.
- 지평선 위 도시 스카이라인(랜드마크)은 지금처럼 하늘 위에 그대로.
```
