엔진 파일을 첨부한 새 lovesim-engine.js로 통째로 교체해줘. (지난 프롬프트 내용은 그대로 유지하고, 아래만 추가/수정)

━━ 1. 첫 화면 (첨부했던 시안 그대로) ━━
- 배경: 인생길 (하늘 + 멀리 도시 + 길가 작은 집들), 뒷모습의 내가 길 "가운데쯤"에서 걷기 — 버튼에 가려지지 않게 화면 세로 중간보다 살짝 아래.
- 맨 위 로고, 그 바로 밑에 작은 흰 글씨 "ⓒ Jellie Studio".
- 화면 아래쪽: 크고 넓은 [START] (핑크, primary).
- 그 아래 한 줄에 secondary 버튼 2개 나란히: [이어하기 Continue] [만든 사람에게 To Creator]
  · 이어하기는 항상 보이게 (저장된 게임이 없으면 흐리게 비활성).
  · 만든 사람에게 → 가운데에서 살짝 확대되며 뜨는 팝업 페이지: "To Creator / ⓒ Jellie Studio / 두근두근, 내 운명의 사람 · Doki Doki Destiny Lover / 사주·점성술·MBTI가 그리는 단 하나의 인연 이야기. 플레이해 주셔서 고마워요 ♥ / Design & story · Jellie Studio" + [닫기]. (문구는 나중에 내가 바꿀 수 있게 한 곳에 모아 둬)
- 로고 두근거림을 훨씬 천천히: 한 박자 3.2초, 크기 변화는 아주 살짝 (1 → 1.04 → 1 → 1.025 → 1). 한국어 ⇄ 영어 로고 교체도 6.4초마다 (두 박자마다).
- START → 언어 팝업: 위에서 떨어지지 말고 "가운데에서 점점 커지며(zoom in)" 등장. 버튼 둘 다 secondary 스타일(크림색)로, 순서는 [English] 위, [한국어] 아래.

━━ 2. 설정 화면 ━━
- "어디서 태어났나요?" 바로 밑에 "현재 어디 살고 있나요?" 추가:
  · 라벨/기본값/안내: LoveSim.setupDefaults(lang).homeQuestion / .home / .homeHint ("사주·점성술엔 영향 없어요. 이야기의 무대가 돼요.")
  · 태어난 곳과 같은 도시 목록. 고른 값을 createGame({ ..., home }) 로 넘기기. (안 넘기면 태어난 곳에서 시작)
- 운명의 상대 "지금 두 사람, 어떤 사이인가요?" 선택지가 5개: fatedOptions(lang).statuses 그대로
  · 네, 지금 결혼했어요 (married) / 네, 지금 사귀고 있어요 (dating) / 썸 / 아는 사이 / 서로 몰라
  · married, dating 은 dateLabel 이 있어 ("결혼한 날" / "사귀기 시작한 날") → 바로 아래 날짜 입력(년·월·일) 보여주고 fated.since = { year, month, day } 로 넘기기.
  · 이야기는 그날부터 시작해 (결혼했으면 결혼한 날부터, 사귀면 사귄 날부터). 모르는 사이/썸이면 내 청춘(20살)부터 시작.
- [✨ 전부 운명에 맡기기]를 골랐을 때 상대 캐릭터는 반드시 game.fated() = { gender, seed } 로 그리기. 절대 기본값(여자)로 그리지 말기. (남자를 좋아한다고 했으면 항상 남자)

━━ 3. 캐릭터 디자인 ━━
- 액세서리 모자: 지금은 공사장 안전모처럼 보여. 앞에 챙이 길게 튀어나온 야구모자(볼캡)로 바꿔줘 — 둥근 돔 + 앞 챙 + 이마 위 단추, 색은 하늘색 / 빨강 / 데님(청바지 파랑) 중에서.
- 비행기 좌석(plane_seat) 등 소품 크기는 캐릭터 키를 넘지 않게: 좌석은 캐릭터 키의 80% 정도.

━━ 4. 상단 상태바 ━━
- 내용 가운데 정렬 (윗줄 날짜·나이, 아랫줄 직업·연애·돈 모두 가운데).
- 영어판 나이는 이제 "37 yrs" 로 와 (hud().age). 숫자만 크게 쓰고 싶으면 hud().ageNum + 작은 "yrs"/"세".

━━ 5. 팝업 흐름 (중요) ━━
- 팝업이 연달아 확확 넘어가는 문제: 팝업을 닫은 뒤에는 최소 3초 동안 걷기만 하고 (시계는 멈추고 길만 스크롤) 그 다음에 advance() 를 다시 진행. 그래서 팝업이 절대 바로 이어서 뜨지 않게 (연속은 최대 3개 정도로 느껴지게).
- 하루가 끝날 때(dayEnd): "시간이 흐른다…"로 넘어가기 전에 3초 더 걷기 (길 계속 스크롤).
- 이름 중복 금지: 팝업/결과의 말하는 사람은 popup.name / 결과의 name 만 쓰고, 대사 앞에 [아빠], [카드사] 같은 대괄호 이름을 절대 붙이지 마. (엔진이 대사에서 이미 떼어 줘)
- 새 팝업 종류 source "occasion": 100일, 사귄 n주년, 결혼 n주년, 내 생일·상대 생일이 다가올 때 (매년은 아니고 가끔). 큰 팝업(big)으로 다른 이벤트처럼 처리하면 돼.
- 부모님의 마지막 밤 → 부고 → 빈자리, 이별할 때 멀어지는 마음 → 마지막 저녁 → 돌아서는 길 → 안녕 도 이제 하루 안에 이어서 와 (사이사이 3초 걷기).

━━ 6. 인생길 ━━
- 커플이 걸을 때 간격: 지금 너무 붙어 있어. 밧줄 없앤 것만 빼고 예전 간격(사람 한 명 폭 정도)으로 되돌려줘.
- "연애 중"이 뜨는 순간부터 상대가 항상 같이 걸어 (장거리 연애 중에도). walkers 의 apart: true 면 상대를 55% 정도 투명하게 (마음으로 함께 걷는 느낌).
- 구름: game.road().backdrop.sky.cloudMotion = { cover, speed, shape } 로 구름이 왼→오른쪽으로 계속 흘러가게:
  · cover 0~1 → 화면에 구름 약 2~9개, speed = 1분에 화면 폭의 몇 배를 지나가는지 (0.1 = 10분에 한 번 가로지름)
  · shape: "puffy"(낮의 뭉게구름) / "streaks"(노을의 가늘고 긴 구름) / "wisps"(밤의 흐릿한 구름) / "overcast"(비 오는 날 회색 하늘 덮개)
  · 구름 색은 sky.clouds.
- 여행 중이면 장소 표시가 여행 도시로 와 (예: 📍 도쿄 거리 · 일본 · 도쿄). 엔진 값 그대로.

━━ 7. 게임 속도 ━━
- 지금 내가 쓰는 개발용 30x 속도를 새 1x(보통 속도)로. 2x, 5x 는 그 기준으로.

━━ 8. 참고 (엔진에서 고친 것 — UI 변경 없음) ━━
- 주말 "오늘 ○○와 뭐 할까?" 선택지가 훨씬 자유롭고 재밌어졌어 (한강 치맥, 인생네컷, 커플링 공방, 새벽 편의점 라면…). 사는 나라에 따라 달라 (일본: 이자카야·불꽃놀이, 프랑스: 센 강 피크닉, 미국·영국: 드라이브인 영화관…). 고르면 그 선택지만의 짧은 대답이 와.
- 온라인 첫 만남이 다양해짐: 언어교환 앱뿐 아니라 소개팅 앱, 인스타그램 댓글, 팬 커뮤니티 쪽지.
- 상대가 사는 도시는 내가 사는 곳 기준으로 판단 (나는 미국, 상대는 부산 → 해외 장거리). 고른 도시가 엉뚱한 도시로 바뀌지 않아.
- 형제는 이름 없이 "형이 결혼했다", "누나가…" 처럼만. "새로운 친구가 n명 생겼다" 줄은 삭제.
- 이별/이혼 전에는 항상 4장짜리 작별 시퀀스가 와.
