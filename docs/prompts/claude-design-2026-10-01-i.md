```
엔진 파일을 첨부한 새 lovesim-engine.js로 통째로 교체해줘. (지난 프롬프트 내용은 그대로 유지하고, 아래만 추가/수정)

━━ 1. 이벤트 팝업 제목 띠 색 ━━
- 지금의 짙은 남색 그라데이션 대신, 살짝 톤 다운된 파스텔 "뽀용뽀용한" 그라데이션으로:
  하늘색 → 민트 (예: 왼쪽 #A9D4EE → 오른쪽 #B5E6D6, 테두리는 한 톤 진하게 #8DBFD8). 채도 낮게, 부드럽게.
- 제목 글씨는 그대로 하얀색. (글씨가 묻히면 아주 옅은 그림자 rgba(60,90,120,0.25) 1px 정도만)

━━ 2. 메시지(문자 토스트) ━━
- 문자가 뜨는 위치의 왼쪽 시작점을 아래 장소 표시(📍 …) 글상자의 왼쪽 시작점과 똑같이 맞춰줘 (같은 x 좌표, 같은 좌우 여백).
- 문자 상자의 그림자 색을 핑크로 바꾸고 투명도를 낮게: 예) box-shadow 0 2px 6px rgba(255, 140, 180, 0.25).

━━ 3. 설정 화면: 국적 추가 ━━
- 나: "어디서 태어났나요?" / "현재 어디 살고 있나요?" 와 같은 페이지에 "국적은?" 고르기 추가.
  · 라벨/안내: LoveSim.setupDefaults(lang).nationalityQuestion / .nationalityHint
  · 목록: LoveSim.nationalityOptions(lang) → [{ id: "KR", name: "한국" }, …] (한국이 맨 위)
  · 기본값 = 태어난 곳 도시의 나라 (태어난 곳을 바꾸면 국적 기본값도 같이 따라가게, 단 직접 고른 뒤엔 그대로)
  · createGame({ ..., nationality: "<id>" }) 로 넘기기.
- 운명의 상대: 태어난 곳 바로 아래에 "그 사람의 국적은?" (setupDefaults(lang).fatedNationalityQuestion), 같은 목록. 기본값 = 상대가 태어난 곳의 나라 → fated: { ..., nationality: "<id>" }.
  · [✨ 전부 운명에 맡기기] 일 땐 숨기기.
- 국적 고르기도 도시처럼 검색 + 목록에서 눌러야 확정.

━━ 4. 참고 (엔진에서 고친 것 — UI 변경 없음) ━━
- 국적이 이야기에 반영돼: 해외에 살면 그리운 게 "한인마트"(한국인) / "일본 식료품점"(일본인)처럼 달라지고, 가족은 국적의 나라에 살아 (집에 가는 비행기). 입영 통지서는 한국 남자만. 국적이 다른 커플은 상견례에 번역 앱이 등장.
- 학생(또는 무직)으로 시작하면 초반에 큰 팝업 "학자금 대출"(또는 "마이너스 통장")이 와: 결과 문장 "😢 [학자금 대출] 때문에 빚이 생겼다…". 이 결과 문장 안의 대괄호는 말하는 사람 이름이 아니라 그대로 보여줘야 하는 글자야 (😢로 시작해서 엔진이 이름으로 떼지 않아).
- 거리가 먼 장면은 항상 이동 문장이 앞(또는 뒤)에 붙어: "(Jung이 도쿄에서 비행기를 타고 왔다.)", "(갑작스러운 소식에 급히 비행기를 탔다…)", "(가장 빠른 타이베이행 비행기를 탔다. 가는 내내 손이 떨렸다.)". 엔진 문장 그대로 쓰면 돼.
```
