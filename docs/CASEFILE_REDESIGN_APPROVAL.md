
# Case File 리디자인 승인안

Big Green Bear's Adventure 2 · Loki 검토용. 인물, 증거, 노트, 사건 재구성에 들어갈 내용 전부.

**읽는 법**

- 이 문서는 Loki의 4탭 안(인물 · 증거 · 사건 재구성 · 추리 노트)을 현재 게임 코드와 실제 텍스트에 맞춰 구체화한 것이다. 코드는 아직 바꾸지 않았다.
- 증거 분류는 **코드에서 실제로 얻을 수 있는지**로 판정했다. 새 스크립트 대사에서 지급되면 「유지」, 옛 6·7장 플래그(`c6.on`)에 묶여 지금은 얻을 수 없으면 「옛 시스템」이다.
- 공개 조건(몇 장에서 열리는지)은 코드 흐름을 보고 쓴 초안이라 확인이 필요하다.
- 화면 실제 모습은 확인하지 않았고, 아래 새 문장(인물 소개, 추리 질문)은 **초안**이다. 새 스토리 사실을 만들지 않도록 기존 증거와 설정집 문장만 근거로 썼다.

## 0. 승인이 필요한 결정 (한눈에)

1.  **탭 4개**: 인물 / 증거 / 사건 재구성(타임라인+지도) / 추리 노트. 기존 「조사」 탭 제거. 승인?
2.  **자동 노트 폐지**: 증거마다 붙던 노트 한 줄(약 80줄)을 없앤다. 승인?
3.  **진술(STATEMENT) 5건(+확인 필요 1건)은 증거 탭에서 빼고 인물 탭으로 이동**. 승인?
4.  **증거 55개 정리**(표 3.3): 유지 23개, 인물 탭 이동 5개, 통합 9개, 삭제 후보 3개, 옛 시스템이라 **결정이 필요한 15개**. 15개는 3.3에서 하나씩 정해 주세요.
5.  **그린은 처음에 보이지 않음**: 빈 슬롯도 두지 않는다. 인물 칸 수도 처음부터 알리지 않는다.
6.  **추리 질문 7개 + 마지막 선택** 초안(섹션 5) 승인 및 수정.
7.  **지도**: 장소 8곳, 현재 위치는 플레이어 위치와 연동(섹션 4).

## 1. 탭 구조

| 탭          | 질문                     | 들어가는 것                                                                 | 잠금/공개                 |
|-------------|--------------------------|-----------------------------------------------------------------------------|---------------------------|
| 인물        | WHO · 누가 무엇을 아는가 | 인물 카드 8명, 진술, 관련 증거, 미해결 질문. 정체 보드는 특별 페이지로 이동 | 만난 사람만 공개          |
| 증거        | WHAT · 무엇을 발견했나   | 사건별 묶음 카드, 묶음 안의 개별 발견, 필터                                 | 얻은 것만 표시            |
| 사건 재구성 | WHEN / WHERE             | 시간순 보기, 장소별 보기(지도). 알지 못하는 시각은 「?」                    | 얻은 증거 기준            |
| 추리 노트   | WHY · 무엇이 모순인가    | 미해결 질문, 연결된 단서, 내가 내린 결론                                    | 챕터 진행으로 질문이 열림 |

제거: 「조사」(책임 보드 3열, 옛 6장 결론 6개, 「놓친 것들」 페이지)와 독립 「지도」 탭. 필요한 기능은 사건 재구성과 추리 노트로 옮긴다.

#### 정체 보드의 이동

기존 「정체 보드」(빅그베 사진과 그린 「?」 슬롯, 손잡이·목도리 매듭·귀 흉터·사진 설명·장부 잉크 5개 단서 카드)는 인물 탭 고정 UI에서 빼고, 관련 단서를 모으면 열리는 **특별 추리 페이지**로 이동. 단서 카드 내용은 그대로 쓴다. 매듭·흉터 카드는 옛 6장 플래그에 묶여 있어 새 4·5장(회상) 진행 조건으로 교체가 필요하다.

## 3. 증거 탭

### 3.1 화면 규칙

- 내부 데이터는 삭제하지 않고 `group`(묶음)과 `kind`(분류)만 추가한다.
- 한 묶음은 카드 1장으로 보이고, 눌러서 안의 개별 발견을 본다. 모순을 만드는 물건(탑시계 vs 회중시계)은 개별 선택 가능.
- 필터: 현장 / 기록 / 사진·숨긴 물건 / 소견 / 카페.

## 5. 추리 노트

자동 일기장은 없앤다. 남기는 것은 세 가지: **질문 제시 · 관련 증거 연결 · 내가 내린 결론**. 각 질문은 챕터가 진행되면 열리고, 답을 고르지 않아도 진행은 막히지 않는다. 아래 질문 문장은 초안이다(새 스토리 사실을 넣지 않기 위해 이미 게임에 나온 사실만 사용했다).

1장  
**Q. 다리(11:35)와 계단(11:40)에서 목격된 목도리 곰은 같은 인물인가?**  
연결 단서: 진술: 토미, 진술: 올리버  
결론 선택지: 같은 인물이다 / 다른 인물이다 / 아직 모르겠다

2장  
**Q. 탑시계가 멈춘 11:47은 에드워드가 죽은 시각인가?**  
연결 단서: 멈춰 선 시계, 에드워드의 깨진 회중시계, 추정 사망 시간  
결론 선택지: 그렇다 / 아니다 / 아직 모르겠다

2장  
**Q. 계단의 곰은 오른손에 무엇을 들고 있었나? 그 곰은 빅그베인가?**

결론 선택지: (손잡이 단서를 모은 뒤 결론)

3장  
**Q. 에드워드의 편지 두 통은 누구에게 쓴 것인가?**  
연결 단서: 에드워드의 편지 초안, 진술: 니니  
결론 선택지: (수신자 후보에서 선택)

3장

결론 선택지: 고장이었다 / 누가 망가뜨렸다 / 아직 모르겠다

4~5장  
**Q. 23년 전 기록은 누가, 왜 바꿨나?**

결론 선택지: (회상 장면 이후 결론)

6장  
**Q. 에드워드는 마지막에 무엇을 하려 했고, 빅그베가 도착했을 때 그는 어떤 상태였나?**  
연결 단서: 추정 사망 시간, 노란 실, 숨겨진 편지와 장갑  
결론 선택지: (메이의 소견과 숨긴 물건을 근거로)

**마지막 질문(8번)**: 기존 6장 마지막 선택(니니의 최종 선택, 엔딩 A/B)을 추리 노트의 마지막 질문으로 연결한다. 「진실을 알게 된 뒤 어떻게 받아들일 것인가」. 선택지 문구는 지금 게임의 엔딩 선택 문구를 그대로 쓴다.
