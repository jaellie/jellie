# Case Journal 와이어프레임 (Thor → Loki)

기준: 게임 무대 1920×1080(고정 크기, 화면에 맞춰 축소). 내부 기능(`PEOPLE`, `EV_META`, `QS`, `TL_DATA`, `PLACES`, `S.qa`)은 그대로 쓰고 보이는 화면만 교체한다. 인터랙티브 와이어프레임 페이지(탭 4개, KO/EN, 긴 글 시험, 치수 표시)를 함께 제출한다.

- 글자 크기 하한: 본문 28px, 칩 24px, 라벨 22px(대문자 자간), 배지 20px. 20px 미만 없음.
- 스크롤: 긴 영역은 안쪽 스크롤, 아래쪽 46px 종이색 페이드와 가는 황동 스크롤바. 페이지 자체는 스크롤하지 않는다.

## 2. 탭별 레이아웃
### 01 인물 (WHO)
- 왼쪽: 초상 타일 3열, 타일 220×240(초상창 188×170 + 이름). 만난 사람만 흐름 배치, 빈 칸 없음. 최대 8명이라 한 페이지.
- 오른쪽: 위 (1010,164) 초상 프레임 220×260 + (1250,164) 이름 블록 460×260(이름 52px, 직함 30px, 소개 28px). 아래 (1010,444) 700×488 스크롤 영역에 관찰, 진술, 회상에서 본 것, 관련 증거 칩이 단계적으로 늘어난다.

### 02 증거 (WHAT)
- 왼쪽: 묶음 카드 3열×4행, 카드 220×176(아이콘 96 + 이름 24px + 개수 배지), 페이지당 12개, 넘치면 페이지 넘김.
- 오른쪽: 묶음 제목 (1010,164) 40px, 개별 증거 칩 (1010,244) 700×150(최대 3줄), 아이콘 170×170과 이름 (1010,414), 설명 (1010,604) 700×276 스크롤, 연결 정보(장소, 사용된 질문) (1010,884) 700×48.

### 03 사건 재구성 (WHEN / WHERE)
- 왼쪽: 시간순 목록 700×768 스크롤. 행 높이 120 이상, 시각 150px 열 + 배지 + 본문 27px + 증거 칩.
- 오른쪽: 지도 576×600 (기존 양피지 0.9배, 핀과 이름은 코드), 선택한 장소 패널 (1010,780) 700×152(장소명, 증거 칩, 관련 시간). 시간 행 선택은 핀 강조, 핀 선택은 관련 시간 강조. 장소가 확정되지 않은 시간은 핀에 연결하지 않는다. 모드 토글(시간순/장소별)은 없어진다.

### 04 추리 노트 (WHY)
- 왼쪽: 질문 카드 700×136, 한 화면 5개, 스크롤. 상태 배지(조사 중, 판단 기록, 새 단서).
- 오른쪽: 질문 제목 (1010,164) 700×170(최대 3줄), 단서 카드 2열 342×150(근거로 표시, 자세히) (1010,350) 영역 316, 3행째부터 스크롤, 판단 버튼 2×2 342×88 (1010,732). 판단과 근거 표시는 분리 저장(`S.qa[q].v`, `.b`)하고 새 단서가 와도 판단은 바뀌지 않는다.

## 3. 긴 글 대응
- 700px 폭에서 28px 기준 한 줄에 KO 약 25자, EN 약 36자. 영어는 한글보다 1.3~1.5배 길다는 전제로 설계했다.
- 이름·제목은 최대 3줄, 본문은 스크롤. 버튼 글자가 2줄을 넘으면 88px 높이 안에서 줄바꿈하고, 3줄 이상이면 글자를 줄이지 않고 버튼 높이만 늘린다(판단 버튼 영역은 스크롤).
- 와이어프레임의 「긴 글 시험」은 글을 1.5배 늘려 이 규칙이 지켜지는지 보여 준다.

## 4. 상태
기본, 호버, 선택(버건디 테두리 + 붉은 리본), 비활성(이전 저장의 dormant 증거는 점선 칩), 새 단서(리본 배지). 선택은 키보드 방향키와 Enter도 지원.

## 5. 스프라이트와 코드의 구분
| 스프라이트 | 코드(HTML/CSS) |
|---|---|
| 커버 프레임, 페이지 2장, 제본선, 탭 8종, 탭 아이콘, 카드 프레임 6종, 초상 프레임 3종, 클립·테이프·핀·스탬프 틀, 지도 핀·장소 아이콘, 증거 아이콘 24개와 묶음 아이콘 13개, 에드워드·헤이즐 초상 | 모든 글자, 2페이지 배치, 탭 전환, 스크롤, 선택 상태, 단서 연결, 판단 선택 |

텍스트가 들어갈 영역을 이미지에 구워 넣지 않는다. 프롬프트북 J 섹션의 13개 프롬프트가 이 크기와 좌표를 그대로 따른다.

## 6. 구현 순서
1. 와이어프레임 승인(이 문서).
2. 스프라이트 제작: 커버, 페이지, 제본선, 탭, 카드 프레임 먼저. 이 5종이 오면 그림이 없는 아이콘은 임시 아이콘으로 대체해 먼저 화면을 완성한다.
3. HTML/CSS 구현: 기존 렌더 함수(`peoplePage`, `evidencePage`, `reconPage`, `notesPage`)의 출력만 새 2페이지 레이아웃에 배치. 데이터와 저장 구조는 변경 없음.
4. 회귀 테스트: 기존 60개 점검과 KO/EN 긴 글 시험, 해상도 1280×720 확인.
