# Case Journal 비주얼 목업 제출물 (Thor → Loki)

상태: Loki 심사 반영 목업. 스프라이트 13종은 생성하지 않았고 게임 코드도 수정하지 않았다. 목업은 1920×1080 기준이며, 인물과 증거 그림은 현재 게임 에셋을 그대로 썼다. 질감과 틀은 코드로 흉내 낸 임시 표현이다.

## 1. Loki 수정 지시 반영

| 지시 | 반영 |
|---|---|
| 인물: 초상화 중심 카드, 오른쪽 계층 분리 | 이니셜 사각형 대신 실제 초상이 든 폴라로이드 카드(테이프, 약간 기운 각도, 선택 시 버건디 테두리). 오른쪽은 인물 파일: 큰 초상 + 이름·직함 + FILE No. 스탬프, 그 아래 단계별 구역. 「프로필」은 종이 위 본문, 「진술」은 따옴표가 붙은 종이쪽지와 서명(— 이름), 「관찰」은 연필 아이콘 메모, 「회상에서 본 것」은 세피아 이중 테두리 상자, 「관련 증거」는 그림이 붙은 칩 |
| 증거: 문서, 사진, 물리 증거의 시각 차이 | 묶음이 종류에 따라 다른 모양: 문서는 클립 달린 종이, 사진은 테이프 붙은 폴라로이드, 물건은 꼬리표가 달린 트레이. 뒤에 겹친 종이로 묶음을 표현하고 개수 배지. 오른쪽은 전시대 위에 큰 증거, 증거 번호 꼬리표(EXHIBIT), 종류 스탬프, 장소와 질문 연결 칩 |
| 사건 재구성: 시간과 지도 연결, 사실·진술·추정 구분 | 왼쪽 시간 행을 고르면 **빨간 끈이 책 가운데를 건너 지도의 핀으로 이어진다**. 마커가 유형마다 다르다: 확인된 기록은 황동 인장, 목격 진술은 속이 빈 원, 전문가 추정은 빗금 구간 막대. 장소를 알 수 없는 행(11:35, 11:55~12:15)은 끈이 점선으로 끝나고 「이 기록만으로는 장소를 알 수 없다」고 표시한다. 장소 카드에는 관련 시간 |
| 추리 노트: 질문, 증거 확인, 판단 세 단계 | 오른쪽 페이지를 붉은 실 위의 번호 핀 1·2·3으로 구분하고 단계마다 표면을 바꿨다. 1 질문 = 손글씨 라벨과 큰 제목(종이 위 잉크). 2 단서 확인 = 코르크 판에 핀으로 고정한 단서 카드(근거로 표시하면 붉은 핀과 테두리). 3 나의 판단 = 고무 도장 느낌의 선택 블록, 선택하면 붉은 인장 체크. 왼쪽은 사건 색인: 큰 번호와 질문, 원형 도장(조사 중, 판단 기록) |
| 공통: 책갈피 탭, 여백, 가독성, 스크롤 | 탭을 얇은 리본 책갈피(깃발 모양 끝, 단색 + 아이콘 + 글자)로 교체. 활성 탭은 조금 더 튀어나온다. 페이지 안쪽 여백을 늘리고, 본문 글자는 27~28px 이상, 스크롤 영역에는 아래 페이드와 가는 스크롤바 |

## 2. 한국어와 긴 영어 확인
목업 페이지에서 KO/EN과 「긴 글 시험」(글 1.5배)을 켜 4탭 모두 확인했다. EN 탭 이름은 People / Evidence / Events / Deduction이 책갈피 안에 들어간다(초기 안에서 글자가 잘려 책갈피를 넓히고 아이콘을 줄여 해결). 질문 제목은 3줄까지, 본문은 스크롤, 판단 버튼은 2줄까지 줄바꿈된다.

## 3. 공통 스프라이트와 CSS 구현 요소 분리표
(목업의 「스프라이트/CSS 구분」 버튼으로 파랑=스프라이트, 초록=CSS를 화면에서 볼 수 있다.)

| 스프라이트로 제작 (한 번 만들어 모든 탭이 공유) | CSS/코드로 구현 |
|---|---|
| 가죽 커버 프레임(속이 빈 테두리 1700×960), 모서리 황동 | 레이아웃, 좌표, 2페이지 배치 |
| 페이지 종이 2장(780×880, 바깥 가장자리 쪽 종이 단면, 안쪽 제본 그림자) | 러닝 헤더, 모든 글자와 폰트, 손글씨 라벨 |
| 제본선(60×880, 가죽 끈 4개와 황동 리벳) | 선택·호버·비활성 상태 전환 |
| 리본 책갈피 4색(보통, 활성) + 탭 아이콘 4개 | 스크롤, 스크롤 페이드와 막대 |
| 카드 프레임(묶음 카드, 단서 카드, 질문 행의 보통/선택) | 칩, 배지, 타임라인 선과 마커 모양(그라디언트/테두리) |
| 폴라로이드 프레임(인물 타일, 큰 인물), 증거용 종이·꼬리표·전시대 | 빨간 끈(SVG 곡선), 지도 핀 위치와 강조 |
| 소품: 테이프, 클립, 푸시핀, 붉은 핀 머리, 코르크 판, 빈 도장 틀과 체크 인장 | 단계 번호 핀, 점선 실(반복 그라디언트) |
| 지도 핀(보통, 선택, 현재 위치)과 장소 아이콘 8개 | 지도 이미지 배치(기존 양피지 사용), 장소 이름표 |
| 증거 아이콘과 묶음 아이콘, 에드워드·헤이즐 초상 | 칩, 배지의 글자와 색 |

이번 목업의 확정 규칙: 글자는 이미지에 넣지 않는다. 프레임은 고정 크기(무대가 1920×1080 고정 비율이므로)로 제작하고, 카드 프레임만 9-slice로 늘린다.

## 4. 프롬프트북 J 섹션에 필요한 수정 (승인되면 반영)
- 책갈피 탭: 지금의 130×140 탭 → 164×76 리본 책갈피(활성 +5px), 깃발 모양 끝.
- 폴라로이드 프레임에 테이프 변형과 약간 기운 상태를 쓸 수 있도록 평평하게 그리기(회전은 코드).
- 추가 소품: 코르크 판(650×300 9-slice), 증거 전시대(700×300), 증거 꼬리표(300×150), 빈 인장 4종(조사 중, 판단 기록, 체크, 단계 번호 핀).
- 기존 13종은 폐기하지 않고 위 변경분만 개정한다. 승인 전에는 생성하지 않는다.

## 5. 기존 Phase 2 데이터와 진행 로직 유지 계획
보이는 화면만 교체한다. 다음은 변경하지 않는다.
- 데이터: `EV`, `EV_META`, `PEOPLE`, `personView()`, `evGroups()`, `QS`, `TL_DATA`, `PLACES`, `PLACE_OF`, `ROW_PLACE`.
- 저장: `S.ev`, `S.notes`, `S.flags`, `S.qa`(판단 v, 시점 n, 근거 b), `S.vis`.
- 진행: 증거 지급, 질문 공개 조건, 새 단서 표시, 판단이 새 증거에 바뀌지 않는 정책, 장소를 알 수 없는 시간은 연결하지 않는 정책.
- 구현 방식: `renderCF()`와 `peoplePage`, `evidencePage`, `reconPage`, `notesPage`가 만드는 HTML만 새 2페이지 레이아웃의 구조로 바꾼다. 각 탭의 상태 변수(`selPerson`, `selGroup`, `selEv`, `reRow`, `rePlace`, `qSel`)와 클릭 처리 함수는 재사용한다.
- 새로 필요한 UI 상태: 빨간 끈은 DOM 위치 측정으로 계산하는 순수 표시 요소이고 저장하지 않는다.
- 회귀 점검: 기존 60개 점검과 KO/EN 긴 글 시험, 1280×720 해상도를 구현 후에 다시 돌린다.

## 6. 남은 위험
1. 목업의 폰트(Alegreya, 나눔 펜 손글씨)는 임시 선택이다. 한국어 손글씨 폰트의 라이선스와 게임 번들 가능 여부를 확인해야 한다.
2. 빨간 끈은 스크롤 중인 긴 목록에서는 보이는 행에만 걸리도록 처리해야 한다(목업은 보이는 행만 대상).
3. 질감(가죽, 종이, 코르크)은 지금 CSS 노이즈로 흉내 냈다. 최종 스프라이트가 오면 그림 품질을 다시 검수해야 한다.
