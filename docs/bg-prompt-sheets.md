# 배경 픽셀 시트 프롬프트 — 8장씩 3×3 (11번, 총 83장)

## 쓰는 방법
- 시트 하나 = 메시지 하나. 아래 **시트 1 ~ 11** 블록을 하나씩 통째로 복사해서 보내세요 (공통 규칙이 이미 들어 있어요).
- 같은 장소의 시간대·날씨 버전은 같은 시트에 모아 뒀어요. 그래서 방 구조가 똑같이 나와요.
- 받은 시트 그림을 그대로 주시면 제가 칸별로 잘라서 이름을 붙이고, 선명한 픽셀로 다듬어서 게임에 넣을게요.
- 결과가 이상하면 같은 대화에서 한 줄로 고쳐 달라고 하세요:
  - 사람이 나왔을 때: "Remove all people from every tile. Keep everything else the same."
  - 글씨가 나왔을 때: "Remove all labels and writing. Signs show only wavy lines."
  - 여전히 실사 같을 때: "Make it much more pixelated: bigger chunky pixels, fewer colors, flat bright colors, no smooth shading."
  - 가운데 아래에 가구가 있을 때: "In every tile, move furniture out of the bottom-middle; leave that floor empty."
