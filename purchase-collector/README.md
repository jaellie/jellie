# 🛒 단톡방 구매 요청 자동 집계

카카오톡 단체방에 흩어져 올라온 **구매 요청 링크**(다과, 행사 물품 등)를 모아서, 단가만 입력하면 되는 **엑셀 구매요청 집계표**로 만들어 주는 도구입니다.

## 1. 문제: 학사조교 시절 실제로 겪은 일

학과 간담회나 행사를 준비할 때, 필요한 다과와 물품은 참석자들이 각자 단톡방에 쇼핑몰 링크를 올리는 방식으로 받았습니다.

```
[이하늘] https://www.coupang.com/vp/products/...
[이하늘] 종이컵 2박스요
[박서준] 생수 이걸로 부탁드려요 https://smartstore.naver.com/...
[최유진] 저도 종이컵 필요해요 https://m.coupang.com/vp/products/... 1박스
[이하늘] (아까 그 종이컵 다시 올려요) https://www.coupang.com/...&utm_source=share
```

이걸 정리하는 건 제 몫이었습니다.

- 대화를 처음부터 스크롤하며 링크를 하나씩 찾기
- 링크 바로 다음에 따로 보낸 "2박스요" 같은 수량을 짝지어 적기
- 같은 상품인데 PC 링크·모바일 링크·공유 링크로 모양이 달라서 중복인지 일일이 확인하기
- 엑셀에 옮겨 적고 금액 합계를 내서 예산과 비교하기

요청이 수십 건이면 시간이 오래 걸렸고, **빠뜨리거나 두 번 주문할 위험**이 늘 있었습니다.

## 2. 해결

```
카카오톡 "대화 내보내기" (.txt / .csv)
        ↓
① 메시지 읽기     PC · Android · iPhone · Mac 내보내기 형식 자동 인식
② 기간 거르기     --since / --until (이번 행사 기간만)
③ 링크 추출       쇼핑몰 링크와 그 외 링크(설문, 공지) 구분
④ 수량·메모 연결  링크 직후 같은 사람이 3분 안에 덧붙인 말까지 한 요청으로 묶기
⑤ 중복 합치기     추적 파라미터(utm, q, rank 등)와 m./www. 차이를 지워서 같은 상품 판별
        ↓
엑셀 집계표 (단가만 입력 → 금액·합계 자동 계산)
```

**실행 결과 예시** (가상 샘플 대화, `--mask-names` 사용)

| 번호 | 요청일시 | 요청자 | 쇼핑몰 | 요청 내용 | 수량 | 비고 |
|---|---|---|---|---|---|---|
| 1 | 2026-09-30 10:15 | 이*늘 | 쿠팡 | 종이컵 2박스요 / 저도 종이컵 필요해요 1박스 | 3 | 같은 상품 2명 요청: 이*늘(2개), 최*진(1개) |
| 2 | 2026-09-30 11:40 | 박*준 | 네이버 스마트스토어 | 생수 이걸로 부탁드려요 | | |
| 3 | 2026-10-01 15:12 | 정*호 | 11번가 | 현수막은 여기서 주문하면 될 것 같아요 1장이면 됩니다 | 1 | |

- 링크 4개가 3건으로 정리됐습니다. 같은 종이컵의 PC 링크, 모바일 링크, 재공유 링크가 한 줄로 합쳐지고 수량은 더해졌습니다.
- 설문 링크(`forms.gle`)는 구매 요청이 아니므로 **"기타 링크"** 시트로 따로 빠집니다.

**엑셀 파일 구성** ([샘플 파일](docs/sample_구매요청.xlsx))

| 시트 | 내용 |
|---|---|
| 구매요청 | 위 표 + 단가(노란 칸, 직접 입력) · 금액(자동) · 합계(자동) · 처리상태(대기/구매완료/보류/제외 선택) · 링크 클릭 가능 |
| 요약 | 읽은 메시지 수, 요청 건수, 중복 합친 건수, 예상 총액, 요청자별·쇼핑몰별 건수 |
| 기타 링크 | 쇼핑몰이 아닌 링크. 놓친 요청이 없는지 사람이 훑어보는 용도 |

## 3. 설계에서 고민한 점

**① 메신저 계정을 위험하게 만들지 않는다.**
카카오톡을 원격 조작하는 비공식 자동화 도구는 쓰지 않았습니다. 카카오톡의 **공식 기능인 "대화 내보내기"** 파일만 읽습니다. 메신저로 결과를 자동 전송하지도 않습니다.

**② 개인정보는 내 컴퓨터 밖으로 나가지 않는다.**
대화 내용은 외부 서버나 AI로 보내지 않고 내 컴퓨터에서만 처리합니다. 결과 파일을 공유할 때는 `--mask-names` 옵션으로 이름을 `김*수`처럼 가릴 수 있습니다.

**③ AI 없이 규칙으로 처리한다.**
링크 추출, 수량 인식, 중복 판별은 모두 규칙 기반이라 결과가 매번 같고, 왜 그렇게 나왔는지 설명할 수 있습니다. 회계 처리와 연결되는 업무라서 이 점이 중요하다고 판단했습니다.

**④ 최종 판단은 사람이 한다.**
자동화는 "모으고 정리하는 일"까지만 합니다. 실제로 살지(처리상태)와 단가 확인은 담당자가 엑셀에서 직접 합니다. 애매한 링크는 버리지 않고 "기타 링크" 시트에 남겨서 사람이 확인하게 했습니다.

## 4. 사용 방법

### ① 카카오톡에서 대화 내보내기
- **PC**: 채팅방 → 메뉴(≡) → 대화 내용 → **대화 내보내기** → .txt 저장
- **모바일**: 채팅방 → 메뉴(≡) → 설정(⚙) → **대화 내용 내보내기** → 텍스트만 보내기

### ② 실행
Python 3.11 이상이 필요합니다.

```bash
pip install openpyxl     # 엑셀 서식용 (없으면 CSV로 저장)
cd purchase-collector

# 기본: <대화파일>_구매요청.xlsx 생성
python -m purchase_collector 카카오톡대화.txt

# 이번 행사 기간만, 파일 이름 지정
python -m purchase_collector 카카오톡대화.txt --since 2026-09-28 --until 2026-10-03 -o 10월간담회_구매요청.xlsx

# 공유용: 이름 가리기
python -m purchase_collector 카카오톡대화.txt --mask-names
```

| 옵션 | 설명 |
|---|---|
| `--since`, `--until` | 기간 지정 (YYYY-MM-DD, 당일 포함) |
| `-o` | 결과 파일 이름 (.xlsx 또는 .csv) |
| `--mask-names` | 이름 마스킹 |
| `--all-links` | 쇼핑몰이 아닌 링크도 구매 요청으로 포함 |

### ③ 테스트
```bash
python -m unittest discover -s tests
```
`tests/fixtures`의 대화는 모두 **가상의 샘플**입니다.

## 6. 한계와 다음 단계

- 단축 링크(`coupa.ng`, `naver.me`)는 실제 상품 주소를 열어보지 않기 때문에, 같은 상품의 일반 링크와 중복으로 합쳐지지 않을 수 있습니다.
- 수량은 "3개", "2박스"처럼 숫자+단위 표현만 인식합니다. "두 개"처럼 한글로 쓴 수량은 인식하지 못합니다.
- 상품명과 가격은 쇼핑몰 정책상 자동으로 가져오지 않고, 담당자가 확인해서 입력합니다.
- 다음 단계: 행사별 예산 한도를 넣어 초과 여부 표시, 품의서 양식으로 내보내기.
